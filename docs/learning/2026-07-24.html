  • 영어: 파닉스 4단계(sh, ch, th, ph, wh 결합음)와 선박·조선 실무단어 6개를 학습합니다.
  • 전기: 직렬-병렬 혼합회로 해석 방법을 학습합니다.

1. 영어: 파닉스와 엔지니어링 영어

오늘의 파닉스 규칙

  • 규칙: 자음 결합음(consonant digraph, 컨서넌트 다이그래프) sh, ch, th, ph, wh
  • 한글 설명: 두 개의 자음 글자가 만나 원래 각 글자의 소리가 아닌, 하나의 새로운 소리를 냅니다. 두 글자를 따로 읽지 않고 반드시 합쳐서 한 소리로 읽어야 합니다.
  • 소리 내는 방법:
  • sh: 입술을 동그랗게 오므리고 "쉬" (예: ship, 쉽)
  • ch: 혀를 입천장에 붙였다 떼며 "치/취" (예: chip, 칩)
  • th: 혀끝을 윗니와 아랫니 사이에 살짝 물고 "뜨/드" (예: thin, 씬)
  • ph: 아랫입술을 윗니에 살짝 대고 "프" (f 소리와 같음, 예: phone, 폰)
  • wh: 입술을 둥글게 모으고 "위/후" (예: wheel, 윌)
  • 주의할 점: sh와 ch, th는 특히 헷갈리기 쉬우니 입 모양 차이(쉬-입술 오므림, 치-혀가 입천장에 닿음, 뜨-혀가 이 사이에 나옴)를 구분해서 연습하세요.

소리 단위로 읽기

쉬운 일반 단어 3개 (결합음 연습) - 단어: ship (쉽) — SH-IP, "쉬"+"입"을 이어서 "쉽" - 단어: chip (칩) — CH-IP, "치"+"입"을 이어서 "칩" - 단어: thin (씬) — TH-IN, "뜨"+"인"을 이어서 "씬"

전기·엔지니어링 관련 단어 6개 (선박·조선 실무단어 분야) - 단어: vessel - 한글 발음: 베슬 - 소리 나누기: VES(베스) - SEL(설) - 뜻: 선박 - 실무 사용 상황: "Check the electrical system on the vessel."(선박의 전기 시스템을 점검해라)

  • 단어: engine
  • 한글 발음: 엔진
  • 소리 나누기: EN(엔) - GINE(진)
  • 뜻: 엔진, 기관

  • 실무 사용 상황: "The engine room has many cables and panels."(기관실에는 케이블과 패널이 많다)

  • 단어: generator

  • 한글 발음: 제너레이터
  • 소리 나누기: GEN(젠) - ER(어) - A(에이) - TOR(터)
  • 뜻: 발전기

  • 실무 사용 상황: "Test the generator before start-up."(가동 전에 발전기를 시험해라)

  • 단어: pump

  • 한글 발음: 펌프
  • 소리 나누기: PUMP(펌프, 짧은 u)
  • 뜻: 펌프

  • 실무 사용 상황: "Measure the voltage of the pump motor."(펌프 모터의 전압을 측정해라)

  • 단어: valve

  • 한글 발음: 밸브
  • 소리 나누기: VAL(밸) - VE(브)
  • 뜻: 밸브

  • 실무 사용 상황: "Check the valve position before connecting power."(전원을 연결하기 전에 밸브 위치를 확인해라)

  • 단어: system

  • 한글 발음: 시스템
  • 소리 나누기: SYS(시스) - TEM(텀)
  • 뜻: 시스템
  • 실무 사용 상황: "The control system connects the sensor and alarm."(제어 시스템이 센서와 경보를 연결한다)

짧은 기술 문장

  • 영어 문장: Check the ship's electrical system before the test.
  • 한글 발음: 첵 더 쉽스 일렉트리컬 시스템 비포어 더 테스트
  • 직역: 시험 전에 선박의 전기 시스템을 확인해라
  • 자연스러운 번역: 테스트 전에 선박의 전기 시스템을 점검하세요.

  • 핵심 단어: ship, system, test

  • 영어 문장: The generator and pump are connected to the panel.

  • 한글 발음: 더 제너레이터 앤 펌프 아 커넥티드 투 더 패널
  • 직역: 발전기와 펌프가 패널에 연결되어 있다
  • 자연스러운 번역: 발전기와 펌프는 패널에 연결되어 있습니다.

  • 핵심 단어: generator, pump, connect

  • 영어 문장: Measure the voltage of the engine control system.

  • 한글 발음: 메저 더 볼티지 오브 디 엔진 컨트롤 시스템
  • 직역: 엔진 제어 시스템의 전압을 측정해라
  • 자연스러운 번역: 엔진 제어 시스템의 전압을 측정하세요.
  • 핵심 단어: measure, engine, system

2. 전기: 직렬-병렬 혼합회로 해석

혼합회로란

  • 혼합회로(series-parallel circuit, 시리즈-패럴렐 서킷)는 회로의 일부는 직렬로, 일부는 병렬로 연결된 형태입니다.
  • 어제 배운 직렬 합성(R_total = R1 + R2 + ...)과 병렬 합성(1/R_total = 1/R1 + 1/R2 + ...) 공식을 함께 사용해 해석합니다.

해석 순서

  1. 먼저 병렬로 연결된 부분을 찾아 하나의 저항값으로 합성합니다.
  2. 합성한 병렬 저항값을 직렬 부분의 저항값과 더합니다.
  3. 최종 합성저항에 옴의 법칙(V = I × R)을 적용해 전체 전류나 전압을 계산합니다.

예시

  • 회로 구성: R1 = 5Ω(직렬) + (R2 = 10Ω과 R3 = 10Ω이 병렬로 연결)
  • 1단계 (병렬 부분 합성): 1/Rp = 1/10 + 1/10 = 2/10 → Rp = 5Ω
  • 2단계 (직렬로 합산): R_total = R1 + Rp = 5 + 5 = 10Ω
  • 오늘 배운 단어로 연결하면: system 안의 equipment(설비)를 check할 때, 이런 방식으로 회로를 단계별로 해석합니다.

참고: 거제대학교 전기공학과의 정확한 진도(교과목, 커리큘럼 순서)는 공식 자료로 확인하지 못했습니다 — "확인 필요". 위 내용은 전기공학 일반 기초 개념입니다.

3. Python·AI 자동화

파일 처리 기초: 측정값 기록(record)하고 다시 읽기

어제 배운 for문·range와, 오늘 배운 record(기록) 개념을 연결해 측정값을 파일에 저장하고 다시 불러오는 자동화 예제를 만들어봅니다.

# 파일 처리: 측정값을 텍스트 파일에 기록(record)하고 다시 읽기
records = [
    "1번 지점: 정상 - 225V",
    "2번 지점: ALARM - 195V 비정상",
]

# 쓰기 모드("w")로 파일을 열어 각 줄을 기록
with open("voltage_log.txt", "w", encoding="utf-8") as f:
    for line in records:
        f.write(line + "\n")

# 읽기 모드("r")로 파일을 열어 기록된 내용을 다시 출력
with open("voltage_log.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
  • open(파일이름, "w", encoding="utf-8")에서 "w"는 쓰기(write) 모드를 의미하며, 파일이 없으면 새로 만들고 있으면 덮어씁니다.
  • with open(...) as f: 구문을 쓰면 작업이 끝난 뒤 파일이 자동으로 닫혀 안전합니다.
  • 읽을 때는 "r"(read) 모드를 사용하며, for line in f: 로 파일의 각 줄을 하나씩 가져올 수 있습니다.
  • 실제 업무에서는 이런 방식으로 계측 장비의 measure(측정) 결과를 파일에 record(기록)해 이력을 관리합니다(예시 값이므로 검증 필요).

4. 학교·취업 준비

  • 거제대학교 전기공학과 학습: 정확한 학사일정·시간표·교과과정은 학교 공식 포털이나 학과 사무실을 통해 "확인 필요" 상태입니다. 임의로 만들어내지 않습니다.
  • 전기 관련 자격증: 전기기능사·전기산업기사·전기기사 등 일반적인 국가자격증 체계는 존재하나, 사용자가 목표로 하는 구체적인 자격증 종류와 응시 일정은 확인된 바 없어 "확인 필요"로 표시합니다. 정확한 시행 일정은 한국산업인력공단 Q-net(q-net.or.kr) 공고로 확인해야 합니다.
  • 전기·엔지니어링 직무 준비: 오늘 배운 vessel, engine, generator, pump, valve, system 같은 선박·조선 실무단어는 조선소 전기설비, 선박 전장 엔지니어 채용공고에서 자주 등장하는 표현입니다.
  • 복습 계획: 내일은 파닉스 5단계(bl, br, cl, cr, st, tr 등 자음 뭉치)와 고장·조치 실무단어 카테고리(fault, failure, error 등)로 진행할 예정입니다.

  4. 오늘 예시에서 R1 = 5Ω(직렬)이고 병렬 부분 합성저항 Rp = 5Ω일 때, 전체 합성저항은 몇 Ω인가요?
  5. Python에서 파일을 쓰기 모드로 열 때 open() 함수의 두 번째 인자로 무엇을 넣나요?

정답과 설명

  1. th입니다. 혀끝을 이 사이에 살짝 물고 "뜨/드" 소리를 냅니다.
  2. check, system, vessel(또는 electrical) — "선박의 전기 시스템을 점검해라"라는 뜻입니다.
  3. 병렬로 연결된 부분입니다. 병렬 부분을 먼저 하나의 저항값으로 합성한 뒤 직렬 부분과 더합니다.
  4. 10Ω입니다. R_total = R1 + Rp = 5 + 5 = 10Ω입니다.
  5. "w"입니다. 쓰기(write) 모드를 의미하며, 파일이 없으면 새로 만들고 있으면 덮어씁니다.
