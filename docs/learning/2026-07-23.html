1. 영어: 파닉스와 엔지니어링 영어

오늘의 파닉스 규칙

  • 규칙: 자음-모음-자음(CVC, Consonant-Vowel-Consonant, 컨서넌트-바울-컨서넌트) 형태의 단어 읽기
  • 한글 설명: 영어 단어 중 "자음+모음+자음" 세 글자로 이루어진 단어는 각 글자 소리를 따로따로 낸 뒤, 그 세 소리를 빠르게 이어 붙여서 하나의 단어로 읽습니다. 어제 배운 짧은 모음(a, e, i, o, u) 발음을 그대로 가운데 글자에 사용합니다.
  • 읽는 방법(블렌딩, blending): 1. 첫 자음 소리를 짧게 낸다 (예: m) 2. 가운데 짧은 모음 소리를 낸다 (예: a → "애") 3. 끝 자음 소리를 낸다 (예: t) 4. 세 소리를 끊지 않고 빠르게 이어 "맷(mat)"으로 읽는다
  • 주의할 점: 세 소리를 하나씩 따로 말하면(음-아-트) 단어처럼 들리지 않으니, 반드시 이어 붙여서 한 호흡에 읽어야 합니다.

소리 단위로 읽기

쉬운 일반 단어 3개 (CVC 연습) - 단어: mat (맷) — M-A-T, "음"+"애"+"트"를 이어서 "맷" - 단어: pen (펜) — P-E-N, "프"+"에"+"은"을 이어서 "펜" - 단어: run (런) — R-U-N, "르"+"어"+"은"을 이어서 "런"

전기·엔지니어링 관련 단어 6개 (시운전·현장운영 분야) - 단어: test - 한글 발음: 테스트 - 소리 나누기: TE(테, 짧은 e) - ST(스트) - 뜻: 시험, 시험하다 - 실무 사용 상황: "Test the circuit before start-up."(가동 전에 회로를 시험해라)

  • 단어: check
  • 한글 발음: 첵
  • 소리 나누기: CH(치) - ECK(엑)
  • 뜻: 점검하다, 확인하다

  • 실무 사용 상황: "Check the voltage at the terminal."(단자에서 전압을 확인해라)

  • 단어: inspect

  • 한글 발음: 인스펙트
  • 소리 나누기: IN(인, 짧은 i) - SPECT(스펙트)
  • 뜻: 검사하다

  • 실무 사용 상황: "Inspect the cable for damage."(케이블에 손상이 있는지 검사해라)

  • 단어: measure

  • 한글 발음: 메저
  • 소리 나누기: MEA(메, 짧은 e) - SURE(저)
  • 뜻: 측정하다

  • 실무 사용 상황: "Measure the resistance of the wire."(전선의 저항을 측정해라)

  • 단어: connect

  • 한글 발음: 커넥트
  • 소리 나누기: CON(컨, 짧은 o) - NECT(넥트)
  • 뜻: 연결하다

  • 실무 사용 상황: "Connect the sensor to the panel."(센서를 제어반에 연결해라)

  • 단어: disconnect

  • 한글 발음: 디스커넥트
  • 소리 나누기: DIS(디스) - CON(컨) - NECT(넥트)
  • 뜻: 연결을 끊다, 차단하다
  • 실무 사용 상황: "Disconnect the power before repair."(수리 전에 전원을 차단해라)

짧은 기술 문장

  • 영어 문장: Check and test the circuit before start-up.
  • 한글 발음: 첵 앤 테스트 더 서킷 비포어 스타트업
  • 직역: 가동 전에 회로를 확인하고 시험해라
  • 자연스러운 번역: 가동 전에 회로를 점검하고 테스트하세요.

  • 핵심 단어: check, test, circuit

  • 영어 문장: Measure the voltage and record the value.

  • 한글 발음: 메저 더 볼티지 앤 리코드 더 밸류
  • 직역: 전압을 측정하고 값을 기록해라
  • 자연스러운 번역: 전압을 측정한 후 값을 기록하세요.

  • 핵심 단어: measure, voltage, record

  • 영어 문장: Disconnect the cable and inspect the terminal.

  • 한글 발음: 디스커넥트 더 케이블 앤 인스펙트 더 터미널
  • 직역: 케이블 연결을 끊고 단자를 검사해라
  • 자연스러운 번역: 케이블을 분리한 뒤 단자를 검사하세요.
  • 핵심 단어: disconnect, cable, inspect, terminal

2. 전기: 저항의 직렬·병렬 합성과 전력 공식

저항의 직렬 합성

  • 직렬로 연결된 저항은 각 저항값을 그대로 더합니다.
  • 공식: R_total = R1 + R2 + R3 + ...
  • 예시: 5Ω, 10Ω 저항을 직렬로 연결하면 합성저항은 15Ω입니다.

저항의 병렬 합성

  • 병렬로 연결된 저항은 역수를 더한 뒤 다시 역수를 취합니다.
  • 공식: 1/R_total = 1/R1 + 1/R2 + 1/R3 + ...
  • 예시: 10Ω, 10Ω 저항을 병렬로 연결하면 1/R_total = 1/10 + 1/10 = 2/10, 따라서 R_total = 5Ω입니다.
  • 병렬 합성저항은 항상 가장 작은 저항값보다 작아집니다.

전력(Power) 공식

  • 공식: P = V × I (전력 = 전압 × 전류)
  • 어제 배운 옴의 법칙(V = I × R)과 연결하면: P = I² × R 또는 P = V² / R 로도 표현할 수 있습니다.
  • 예시: 전압 20V, 전류 2A가 흐르면 전력은 P = 20 × 2 = 40W 입니다.
  • 오늘 배운 단어로 연결하면: connect한 회로를 test할 때, measure한 전압과 전류값으로 전력을 계산합니다.

참고: 거제대학교 전기공학과의 정확한 진도(교과목, 커리큘럼 순서)는 공식 자료로 확인하지 못했습니다 — "확인 필요". 위 내용은 전기공학 일반 기초 개념입니다.

3. Python·AI 자동화

for문과 range로 여러 측정값 검사하기

어제 배운 if 조건문과, 오늘 배운 test/measure/record 단어를 연결해 여러 개의 측정값을 한 번에 검사하는 자동화 예제를 만들어봅니다.

# for문과 range를 이용해 여러 측정값(measured_voltages)을 순서대로 검사
rated_voltage = 220
tolerance = 0.1
lower_limit = rated_voltage * (1 - tolerance)
upper_limit = rated_voltage * (1 + tolerance)

measured_voltages = [225, 195, 218, 260]  # 여러 지점에서 measure(측정)한 전압값

for i in range(len(measured_voltages)):
    voltage = measured_voltages[i]
    if voltage < lower_limit or voltage > upper_limit:
        print(f"{i+1}번 지점: ALARM - {voltage}V 비정상")
    else:
        print(f"{i+1}번 지점: 정상 - {voltage}V")
  • range(len(measured_voltages))는 리스트의 길이만큼 숫자를 0부터 생성해서, 리스트의 각 위치(index)를 하나씩 가리킵니다.
  • for i in range(...): 구조로 여러 개의 측정값을 반복해서 하나씩 검사(check)할 수 있습니다.
  • 실제 업무에서는 measured_voltages 리스트에 실제 계측 장비에서 record(기록)한 값을 넣어 사용합니다(예시 값이므로 검증 필요).

4. 학교·취업 준비

  • 거제대학교 전기공학과 학습: 정확한 학사일정·시간표·교과과정은 학교 공식 포털이나 학과 사무실을 통해 "확인 필요" 상태입니다. 임의로 만들어내지 않습니다.
  • 전기 관련 자격증: 전기기능사·전기산업기사·전기기사 등 일반적인 국가자격증 체계는 존재하나, 사용자가 목표로 하는 구체적인 자격증 종류와 응시 일정은 확인된 바 없어 "확인 필요"로 표시합니다. 정확한 시행 일정은 한국산업인력공단 Q-net(q-net.or.kr) 공고로 확인해야 합니다.
  • 전기·엔지니어링 직무 준비: 오늘 배운 test, check, inspect, measure, connect, disconnect 같은 시운전·현장운영 용어는 전기설비 시운전, 현장 엔지니어 채용공고에서 자주 등장하는 표현입니다.
  • 복습 계획: 내일은 파닉스 4단계(sh, ch, th, ph, wh 등의 결합음)와 선박·조선 엔지니어링 단어 카테고리로 진행할 예정입니다.
