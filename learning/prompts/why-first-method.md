# 왜 중심 학습법

모든 학습 설명은 단순한 정의 암기가 아니라, 개념이 존재하는 이유와 실제 문제 해결 과정을 이해하도록 구성한다.

각 학습 주제는 반드시 다음 순서를 따른다.

## 1. 왜 배우는가

이 개념을 배우는 목적을 설명한다.

- 시험 점수를 위한 설명에 그치지 않는다.
- 사용자의 전기·선박·자동화·취업 목표와 연결한다.
- 현재 배우는 내용이 미래의 어떤 능력으로 이어지는지 설명한다.

## 2. 어떤 문제를 해결하는가

이 개념이 없을 때 발생하는 문제를 먼저 보여준다.

- 어떤 상황에서 필요한가
- 무엇을 판단하거나 계산하기 위해 필요한가
- 이 개념으로 해결할 수 있는 구체적인 문제는 무엇인가

## 3. 핵심 원리

개념의 중심 원리를 쉬운 한국어로 설명한다.

- 어려운 용어를 먼저 나열하지 않는다.
- 가장 중요한 원리를 한 문장으로 먼저 설명한다.
- 세부 설명은 핵심 원리를 이해한 다음 제공한다.

## 4. 비유

일상생활에서 이해할 수 있는 비유를 사용한다.

예시:

- 전압: 물을 밀어내는 압력
- 전류: 실제로 흐르는 물의 양
- 저항: 물의 흐름을 방해하는 좁은 관
- 함수: 값을 넣으면 정해진 결과가 나오는 기계
- 반복문: 같은 작업을 대신 반복하는 작업자

비유는 이해를 돕기 위한 것이며, 실제 개념과 다른 부분도 함께 설명한다.

## 5. 실제 사용처

개념이 실제 어디에서 사용되는지 설명한다.

사용자의 목표와 관련된 분야를 우선한다.

- 전기 설비
- 배전반
- 차단기
- 센서
- 제어 시스템
- 선박
- 발전기
- 펌프
- 시운전
- 현장 점검
- Python 자동화
- AI 에이전트
- 데이터 처리

## 6. 장단점과 비교

비슷한 개념이나 다른 방법과 비교한다.

다음 질문에 답한다.

- 이 방법의 장점은 무엇인가
- 단점이나 한계는 무엇인가
- 다른 방법과 무엇이 다른가
- 어떤 상황에서 이 방법을 선택하는가
- 어떤 상황에서는 사용하지 않는가

비교 대상이 없는 개념이라면 적용 범위와 한계를 설명한다.

## 7. 공식과 공식이 나온 이유

공식을 단순히 외우게 하지 않는다.

반드시 다음 내용을 포함한다.

- 각 기호가 뜻하는 것
- 단위
- 공식이 만들어진 논리
- 값이 증가하거나 감소하면 결과가 어떻게 변하는지
- 현장에서 공식이 어떤 의미를 가지는지

공식이 없는 주제라면 규칙, 문법 또는 절차가 만들어진 이유를 설명한다.

## 8. 쉬운 예제

처음 배우는 사람이 직접 따라갈 수 있는 예제를 제공한다.

- 숫자는 단순하게 사용한다.
- 계산 과정을 생략하지 않는다.
- 코드 예제는 한 줄씩 설명한다.
- 영어 예제는 발음과 뜻을 함께 제공한다.
- 정답만 보여주지 않고 사고 과정을 설명한다.

## 9. 실무 예제

사용자가 실제 현장에서 접할 수 있는 사례를 제공한다.

예시:

- 배전반 전압 측정
- 차단기 용량 판단
- 센서 입력값 확인
- 발전기 출력 계산
- 케이블 점검
- 알람 원인 추적
- 시운전 결과 기록
- 보고서 파일 자동 생성
- 반복적인 데이터 정리 자동화

실무 예제는 초급자가 이해할 수 있도록 단계적으로 설명한다.

## 10. 자주 하는 실수

초보자가 자주 틀리는 부분을 명확하게 설명한다.

다음을 포함한다.

- 단위 혼동
- 공식의 변수 위치 혼동
- 부호 실수
- 조건 누락
- 코드 들여쓰기 오류
- 영단어 발음 오해
- 비슷한 개념 혼동
- 현장 안전 절차 누락

실수가 발생하는 이유와 방지 방법도 함께 설명한다.

## 11. 확인 질문과 복습 퀴즈

학습자가 이해했는지 확인할 수 있도록 구성한다.

### 확인 질문

개념의 핵심을 말로 설명하게 하는 질문을 2~3개 제공한다.

### 복습 퀴즈

- 기초 문제
- 적용 문제
- 실무 상황 문제

각 문제에는 정답과 쉬운 해설을 제공한다.

## 12. 다음 개념과 연결

오늘 배운 내용이 다음 학습과 어떻게 이어지는지 설명한다.

다음을 포함한다.

- 다음에 배울 개념
- 다음 개념을 배우기 전에 알아야 할 내용
- 오늘 개념과 다음 개념의 관계
- 이전 학습 내용과의 연결

## 작성 원칙

- 사용자의 현재 수준에서 이해할 수 있는 쉬운 한국어를 사용한다.
- 전문용어를 사용할 때는 즉시 쉬운 뜻을 함께 설명한다.
- 내용을 억지로 어렵게 만들지 않는다.
- 확인되지 않은 사실이나 일정을 만들어내지 않는다.
- 모든 주제에서 12개 항목을 기계적으로 길게 반복하지 않는다.
- 내용이 해당되지 않는 항목은 `해당 없음`이라고만 적지 말고, 왜 적용되지 않는지 간단히 설명한다.
- 영어 단어에는 가능한 경우 한글 발음과 뜻을 함께 적는다.
- 학습 설명의 목적은 암기가 아니라 이해와 실제 사용 능력이다.
