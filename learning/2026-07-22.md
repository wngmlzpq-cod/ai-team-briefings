## 영어 학습

### 1. 오늘의 파닉스 규칙
- 규칙: 자음 기본 소리 - V와 B 구별
- 한글 설명: 영어 자음 V와 B는 한글로 적으면 둘 다 "브"처럼 보이지만 실제 소리는 다릅니다. 이 둘을 구별하는 것이 오늘의 규칙입니다.
- 발음 되는 방법:
  - V: 윗니로 아랫입술을 살짝 물고, 입술 사이로 바람을 내보내며 "브으" 소리를 냅니다. (성대가 떨리는 느낌)
  - B: 두 입술을 붙였다가 떼면서 터뜨리듯 "브" 소리를 냅니다. (윗니는 사용하지 않음)
- 주의할 점: voltage를 "보울티지"처럼 B로 발음하면 안 됩니다. 항상 윗니가 아랫입술에 살짝 닿는지 확인하세요.

### 2. 소리 단위로 읽기

- 단어: voltage
- 한글 발음: 볼티지
- 소리 나누기: V(윗니로 아랫입술 물기) - OL(올) - TAGE(티지)
- 뜻: 전압
- 실무영어에서 사용 상황: 정비 절차서에서 "Check the voltage before disconnecting the cable."(케이블 분리 전 전압 확인) 형태로 자주 사용됩니다.

- 단어: current
- 한글 발음: 커런트
- 소리 나누기: C(크) - UR(어r, 혀를 살짝 말기) - RENT(런트)
- 뜻: 전류
- 실무영어에서 사용 상황: "Measure the current with a clamp meter."(클램프 미터로 전류 측정) 처럼 측정 지시문에 사용됩니다.

- 단어: resistance
- 한글 발음: 리지스턴스
- 소리 나누기: RE(리) - SIS(지스) - TANCE(턴스)
- 뜻: 저항
- 실무영어에서 사용 상황: "High resistance may indicate a loose connection."(저항이 높으면 연결 불량 의심) 처럼 고장 진단 문장에 사용됩니다.

- 단어: circuit
- 한글 발음: 서킷
- 소리 나누기: CIR(서r) - CUIT(킷)
- 뜻: 회로
- 실무영어에서 사용 상황: "Open the circuit breaker before starting work."(작업 전 회로차단기 개방) 처럼 안전 절차문에 사용됩니다.

- 단어: wire
- 한글 발음: 와이어
- 소리 나누기: W(우) - IRE(아이어r)
- 뜻: 전선
- 실무영어에서 사용 상황: "Check the wire for damage."(전선 손상 여부 확인) 처럼 점검 지시문에 사용됩니다.

- 단어: terminal
- 한글 발음: 터미널
- 소리 나누기: TER(터r) - MI(미) - NAL(널)
- 뜻: 단자
- 실무영어에서 사용 상황: "Connect the wire to the terminal."(전선을 단자에 연결) 처럼 조립 지시문에 사용됩니다.

### 3. 오늘의 실무영어 단어 (전기기초 분야)
voltage, current, resistance, circuit, wire, terminal

### 4. 짧은 기술 문장

- 자연스러운 번역: 회로차단기가 과전류로부터 패널을 보호합니다.
- 핵심 단어: circuit breaker, protect, overcurrent

- 영어 문장: Connect the cable to the correct terminal.
- 한글 발음: 커넥트 더 케이블 투 더 커렉트 터미널

## 항목1: [카테고리: 항공]
- 제목: 항공기 전기배선 점검(Wire Harness Inspection) 기초 개념
- 내용:
  항공기 전기배선 다발(Wire Harness, 와이어 하네스)은 정기 점검 항목 중 하나이며, 실기 시험과 실무 모두에서 다루는 기본 점검 포인트가 있습니다.

  1. 마찰 손상(Chafing, 체이핑) 점검: 배선이 구조물이나 다른 배선과 접촉하여 피복이 벗겨지는 현상. 육안으로 피복 손상, 노출된 도체(exposed conductor)를 확인합니다.
  2. 연속성 시험(Continuity Test, 컨티뉴이티 테스트): 멀티미터로 배선 양 끝단의 저항이 거의 0Ω인지 확인하여 단선 여부를 판단합니다.
  3. 절연저항 시험(Insulation Resistance Test, 메거 테스트/Megger Test): 배선과 접지(Ground, 그라운드) 사이의 절연 상태를 측정하여 절연 열화(누전 가능성)를 확인합니다. 일반적으로 500V 또는 250V 메거로 측정하며, 판정 기준값은 기종별 정비 매뉴얼(AMM)로 확인 필요.

## 항목2: [카테고리: Python]
- 제목: 전선 전압강하(Voltage Drop) 계산 코드
- 내용:
  전선이 길어지면 저항 때문에 전압이 일부 손실되는데, 이를 전압강하(Voltage Drop, 볼티지 드롭)라고 합니다. 오늘 배운 voltage, current, resistance 단어를 그대로 코드 변수명에 사용해 연습할 수 있습니다.

  ```python
  # 옴의 법칙(Ohm's Law) 기반 전압강하 계산 예시
  current = 5.0          # 전류 (A, 암페어)
  resistance_per_m = 0.02 # 전선 1m당 저항 (Ω/m, 예시 값)
  wire_length = 15        # 전선 길이 (m)

  total_resistance = resistance_per_m * wire_length  # 회로 총 저항
  voltage_drop = current * total_resistance           # V = I x R

  print(f"전선 길이 {wire_length}m, 전류 {current}A일 때 전압강하: {voltage_drop:.2f}V")
  ```

  - 옴의 법칙 V = I × R을 그대로 코드로 옮긴 형태입니다.
  - resistance_per_m 값은 전선 규격(AWG 등)마다 다르므로, 실제 업무에서는 전선 규격표를 참고해 정확한 값을 넣어야 합니다.
  - 주의: 위 저항 값은 설명용 예시이며 실제 전선 규격의 정확한 저항값은 아닙니다(검증 필요).

- D-day: 해당없음 (업무 상시 활용 기술)
- 출처: 자체 (옴의 법칙 공식을 이용한 일반 예시로 작성, 실제 업무 데이터·수치가 아닌 예시 값임)

- 내용:
