## 항목1: [카테고리: 영어]
- 제목: 항공정비 매뉴얼 필수 지시동사 8가지
- 내용:
  정비 매뉴얼(AMM, Aircraft Maintenance Manual / 에어크래프트 메인터넌스 매뉴얼)은 대부분 "~하시오" 형태의 지시문으로 되어 있습니다. 아래 동사만 익혀도 절차서 흐름을 절반은 이해할 수 있습니다.

  1. Remove (리무브) — 제거하다
  2. Install (인스톨) — 장착하다
  3. Inspect (인스펙트) — 점검하다
  4. Torque (토크) — 규정 값으로 조이다 (예: Torque to 50 in-lb → "50 인치파운드로 토크 하시오")
  5. Lubricate (루브리케이트) — 윤활유를 바르다
  6. Replace (리플레이스) — 교체하다
  7. Check for wear (체크 포 웨어) — 마모 여부를 확인하다
  8. Adjust (어드저스트) — 조정하다

  예문: "Remove the panel, inspect for wear, and torque the bolt to 50 in-lb."
  → "리무브 더 패널, 인스펙트 포 웨어, 앤드 토크 더 볼트 투 피프티 인치파운드"
  → (해석) 패널을 제거하고, 마모를 점검한 뒤, 볼트를 50인치파운드로 조이시오.

- D-day: 해당없음 (시험 과목이 아닌 상시 학습)

## 항목2: [카테고리: 항공]
- 제목: 항공기체정비기능사 실기 - 리벳(Rivet) 작업 기초 개념
- 내용:
  리벳(Rivet, 리벳)은 항공기 외피(Skin, 스킨)를 고정하는 대표적인 영구 체결 방법입니다. 실기 시험에서 자주 나오는 핵심 개념 세 가지를 정리했습니다.

  1. 리벳 규격 읽는 법: 예를 들어 "MS20470AD4-6"이라는 리벳 규격에서 "AD"는 재질(2117 알루미늄 합금)을 의미하고, "4"는 리벳 지름(4/32인치 = 1/8인치), "6"은 리벳 길이(6/16인치)를 의미합니다.
  2. 리벳 간격(Pitch, 피치)과 연변거리(Edge Distance, 엣지 디스턴스): 일반적으로 연변거리는 리벳 지름의 2~2.5배, 리벳 간격은 지름의 6~8배가 기준이 됩니다(정확한 기준값은 실기 교재·공식 기준으로 재확인 필요).
  3. 벅테일(Bucktail, 벅테일) 판정: 리벳을 박은 후 반대쪽에 생기는 머리(벅테일)의 지름이 원래 리벳 지름의 1.5배 이상, 높이가 0.5배 이상이면 정상으로 판정합니다.

- D-day: 2026년 9월 시행 예정 (오늘 기준 약 D-40~D-70로 추정) — 정확한 회차 및 시행일자는 한국산업인력공단 Q-net(q-net.or.kr) 공고로 확인 필요
- 출처: 자체 (일반적인 항공정비 실기 기준 정리, 정확한 배점·판정 기준은 공식 출제기준으로 검증 필요)

## 항목3: [카테고리: Python]
- 제목: 성능 계산 업무에 쓰는 선형 보간법(Linear Interpolation) 코드
- 내용:
  항공기 성능 차트(예: 이륙거리, 착륙거리 표)는 특정 온도·중량·고도 값에서만 표로 제공되기 때문에, 그 사이 값은 보간법(Interpolation, 인터폴레이션)으로 계산합니다. Python의 numpy 라이브러리를 쓰면 간단히 처리할 수 있습니다.

  ```python
  import numpy as np

  # 예시: 중량(kg)에 따른 이륙거리(m) 데이터 (표에서 가져온 기준점)
  weight_table = [1000, 1200, 1400, 1600]      # kg
  distance_table = [350, 410, 480, 560]        # m

  # 실제 중량이 1300kg일 때 이륙거리 추정
  actual_weight = 1300
  estimated_distance = np.interp(actual_weight, weight_table, distance_table)

  print(f"{actual_weight}kg일 때 예상 이륙거리: {estimated_distance:.1f}m")
  ```

  - np.interp(찾으려는 값, x축 기준표, y축 기준표) 형태로 사용합니다.
  - 표에 없는 중간값을 자동으로 직선 비례 계산(linear interpolation, 리니어 인터폴레이션)해 줍니다.
  - 주의: 실제 성능표는 온도·고도 등 변수가 2개 이상인 경우가 많아, 이때는 2차원 보간(bilinear interpolation, 바이리니어 인터폴레이션)이 필요합니다. 필요하면 scipy.interpolate.griddata를 활용할 수 있습니다.

- D-day: 해당없음 (업무 상시 활용 기술)
- 출처: 자체 (numpy 공식 문서의 np.interp 사용법 기준 일반 예시로 작성, 실제 업무 데이터·수치가 아닌 예시 값임)
