## 1. 영어: 파닉스와 엔지니어링 영어

### 오늘의 파닉스 규칙
- 규칙: 짧은 모음(short vowel, 쇼트 바울) a, e, i, o, u
- 한글 설명: 영어 단어 가운데에 오는 모음 a, e, i, o, u는 길게 늘이지 않고 짧고 툭 끊어서 발음합니다. 우리말 "아, 에, 이, 오, 어"와 비슷하지만 훨씬 짧게 끊습니다.
- 입모양과 소리 내는 방법:
  - a: 입을 옆으로 살짝 벌리고 짧게 "애" (예: cat, 캣)
  - e: 입을 조금만 벌리고 짧게 "에" (예: bed, 베드)
  - i: 입을 거의 안 벌리고 짧게 "이" (예: sit, 씻)
  - o: 입을 동그랗게 살짝 벌리고 짧게 "아" (예: hot, 핫)
  - u: 입을 편하게 두고 짧게 "어" (예: cup, 컵)
- 주의할 점: 모음을 길게 늘이면(예: "케에엣") 다른 단어처럼 들릴 수 있으니 짧고 명확하게 끊어 발음하세요.

### 소리 단위로 읽기

**쉬운 일반 단어 3개**
- 단어: cat (캣) — C-A-T, 짧은 "애" 소리
- 단어: bed (베드) — B-E-D, 짧은 "에" 소리
- 단어: cup (컵) — C-U-P, 짧은 "어" 소리

**전기·엔지니어링 관련 단어 6개 (제어·계장 분야)**
- 단어: sensor
  - 한글 발음: 센서
  - 소리 나누기: SEN(센, 짧은 e) - SOR(서r)
  - 뜻: 센서
  - 실무 사용 상황: "The sensor detects abnormal temperature."(센서가 비정상 온도를 감지한다)

- 단어: signal
  - 한글 발음: 시그널
  - 소리 나누기: SIG(시그, 짧은 i) - NAL(널)
  - 뜻: 신호
  - 실무 사용 상황: "Check the signal from the control panel."(제어반에서 오는 신호를 확인해라)

- 단어: control
  - 한글 발음: 컨트롤
  - 소리 나누기: CON(컨, 짧은 o) - TROL(트롤)
  - 뜻: 제어
  - 실무 사용 상황: "The control system stops the pump automatically."(제어 시스템이 자동으로 펌프를 멈춘다)

- 단어: alarm
  - 한글 발음: 얼람
  - 소리 나누기: A(어) - LARM(람)
  - 뜻: 경보
  - 실무 사용 상황: "The alarm activates when voltage is too high."(전압이 너무 높으면 경보가 울린다)

- 단어: input
  - 한글 발음: 인풋
  - 소리 나누기: IN(인, 짧은 i) - PUT(풋)
  - 뜻: 입력
  - 실무 사용 상황: "Check the input value before starting the test."(시험 시작 전 입력값을 확인해라)

- 단어: output
  - 한글 발음: 아웃풋
  - 소리 나누기: OUT(아웃) - PUT(풋)
  - 뜻: 출력
  - 실무 사용 상황: "Measure the output voltage of the sensor."(센서의 출력 전압을 측정해라)

### 짧은 기술 문장
- 영어 문장: The sensor sends a signal to the control panel.
  - 한글 발음: 더 센서 센즈 어 시그널 투 더 컨트롤 패널
  - 직역: 센서가 신호를 제어반으로 보낸다
  - 자연스러운 번역: 센서가 제어반으로 신호를 보냅니다.
  - 핵심 단어: sensor, signal, control panel

- 영어 문장: Check the input and output values.
  - 한글 발음: 첵 디 인풋 앤 아웃풋 밸류즈
  - 직역: 입력값과 출력값을 확인해라
  - 자연스러운 번역: 입력값과 출력값을 확인하세요.
  - 핵심 단어: check, input, output

- 영어 문장: The alarm goes off if the current is abnormal.
  - 한글 발음: 디 얼람 고즈 오프 이프 더 커런트 이즈 어브노멀
  - 직역: 전류가 비정상이면 경보가 울린다
  - 자연스러운 번역: 전류가 비정상이면 경보가 작동합니다.
  - 핵심 단어: alarm, current, abnormal

## 2. 전기: 기초회로 또는 전기자기학

### 직렬회로와 병렬회로
- 직렬회로(series circuit, 시리즈 서킷): 전류가 흐르는 길이 하나뿐이라 모든 지점에서 전류(current)가 같습니다. 부품 하나가 끊어지면 회로 전체가 멈춥니다.
- 병렬회로(parallel circuit, 패럴렐 서킷): 전류가 흐르는 길이 여러 개라 각 갈래마다 전류가 나뉘고, 전압(voltage)이 각 갈래에서 같습니다. 부품 하나가 끊어져도 다른 갈래는 계속 작동합니다.

### 옴의 법칙 (Ohm's Law) 복습
- 공식: V = I × R (전압 = 전류 × 저항)
- 오늘 배운 단어로 연결하면: control 시스템이 input 전압을 받아 계산하고, 저항(resistance)이 커지면 같은 전류를 흘리기 위해 더 큰 전압이 필요합니다.
- 예시: 저항이 10Ω인 회로에 전류 2A가 흐르면, 전압은 V = 2 × 10 = 20V 입니다.

### 전기안전 기초
- 회로 작업 전에는 항상 전원을 차단(disconnect)하고 무전압 상태를 확인합니다.
- 경보(alarm)가 울리면 먼저 계기판의 신호(signal)를 확인하고, 원인을 파악하기 전에는 임의로 재설정(reset)하지 않습니다.

> 참고: 거제대학교 전기공학과의 정확한 진도(교과목, 커리큘럼 순서)는 공식 자료로 확인하지 못했습니다 — "확인 필요". 위 내용은 전기공학 일반 기초 개념입니다.

## 3. Python·AI 자동화

### if 조건문으로 전압 이상 감지하기
어제 배운 전압강하 계산과, 오늘 배운 sensor/alarm 단어를 연결해 간단한 이상 감지 자동화 예제를 만들어봅니다.

```python
# if 조건문을 이용한 전압 이상(alarm) 감지 예시
rated_voltage = 220      # 정격 전압 (V)
measured_voltage = 195   # 센서(sensor)가 측정한 전압 (V)
tolerance = 0.1          # 허용 오차 10%

lower_limit = rated_voltage * (1 - tolerance)
upper_limit = rated_voltage * (1 + tolerance)

if measured_voltage < lower_limit or measured_voltage > upper_limit:
    print("ALARM: 전압이 정상 범위를 벗어났습니다.")
else:
    print("정상: 전압이 정상 범위 안에 있습니다.")
```

- `if` ~ `else` 구조로 측정값(measured_voltage)이 정상 범위(lower_limit ~ upper_limit)를 벗어나면 경보 메시지를 출력합니다.
- `or` 연산자로 "너무 낮거나(lower_limit 미만) 너무 높은(upper_limit 초과)" 두 조건을 하나의 if문에 담았습니다.
- 실제 업무에서는 이 tolerance(허용 오차) 값과 정격 전압을 설비 사양서에서 확인해 정확한 값을 넣어야 합니다(예시 값이므로 검증 필요).

## 정답과 설명

3. 병렬회로입니다. 병렬회로는 전류가 흐르는 길이 여러 개라 한 갈래가 끊어져도 다른 갈래는 계속 작동합니다.
4. V = I × R (전압 = 전류 × 저항) 입니다.
5. `or` 연산자입니다. `if a or b:` 형태로 쓰면 a와 b 중 하나만 참이어도 조건문이 실행됩니다.
